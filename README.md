# Grammify
Grammify is a lightweight, offline English Grammar Tutor AI that teaches grammar rules, corrects sentences, and provides examples using a smart rule-based system without any API.
Grammify

Grammify is a simple, offline English Grammar Tutor AI built using HTML, CSS, and JavaScript. It helps users learn English grammar by providing clear explanations, examples, and instant corrections — without using any external API.

🚀 Features
📘 Grammar explanations (A1–B2 level)
✍️ Sentence correction with mistakes highlighted
💡 Examples for every topic
🧠 Rule-based AI system (no API required)
💬 Chat-style learning interface
⚡ Fast and lightweight
📚 What Grammify can teach
Nouns, verbs, adjectives, adverbs
Tenses (present, past, future)
Modals (can, must, should, etc.)
Articles (a, an, the)
Prepositions
Conditionals
Reported speech
Gerunds & infinitives
Phrasal verbs (expandable)
🛠️ How it works

Grammify uses a rule-based system:

Detects keywords from user input
Matches them with grammar database
Returns:
Definition
Rules
Examples
Common mistakes

No internet or API is required.
